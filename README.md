# Orbit

A music player built in TypeScript on top of a doubly linked list. Search any song, queue it at the start, the end or any position, and play it in full while a 3D particle sphere reacts to the music and to your cursor.

## Features

- Add songs at the head, the tail or any position
- Remove songs, including the one currently playing
- Skip forward and backward through the list
- Shuffle, repeat, drag to reorder, keyboard shortcuts
- Live node visualizer showing head, tail and prev/next pointers

## Stack

Vite, TypeScript, Three.js, GSAP, Vitest, Playwright, Vercel Functions.
